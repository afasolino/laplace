# Frozen offline evaluation fixtures

`frozen_suite_v1.json` is a provider-independent, synthetic suite. The Python and
SystemVerilog trees are deliberately tiny patch-applicability fixtures. No entry is a
measurement of a live model, private corpus or production repository.

Changes require a suite-ID bump and review of expected outcomes. Every result is
reported under infrastructure correctness or fixture task quality. Live-model quality
remains `BLOCKED_BY_USER_CONSTRAINT_GPU_UNAVAILABLE` in this certification.
